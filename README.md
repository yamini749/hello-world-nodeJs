# Hello World Node.js App 👋

A simple Node.js application that outputs "Hello World". Ideal as a starter for learning Node.js or testing deployments.

## 🚀 Features

- Lightweight “Hello World” server
- Runs using `npm start`
- Easily extensible for learning or demos

## 🧰 Prerequisites

- [Node.js](https://nodejs.org/) (version 12+ recommended)
- npm (bundled with Node.js)

## 🛠️ Installation

```bash
git clone https://github.com/yamini749/hello-world-nodeJs.git
cd hello-world-nodeJs
npm install
